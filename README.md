# downloaderMods
Автозагрузчик модов для Minecraft.

### Использование
ЗАПУСКАТЬ main.py!!!! download.py НЕ ТРОГАТЬ!

После запуска кода у вас в папке с main файлом появится два файла:

- *settings.json*
- *not_found_mods.json*

В *settings.json* находится версия, на которую вам нужно скачать моды, а также список самих модов, которые необходимо скачать.
Для примера у вас указаны два мода: *stendhal* и *sodium*. Вы можете спокойно их заменить на свои моды, они не обязательны.

В *not_found_mods.json* автоматически записываются не найденные моды, чтобы потом была возможность быстро прогнать недостающие моды.

Все моды **обязаны** быть на сайте modrinth! Загрузка происходит именно с этого сервиса.

**Как правильно указывать название мода:**\n
Возьмем в пример мод Fabric Api. Нам необходимо найти страницу Fabric Api на сайте modrinth. Далее мы смотрим ссылку (https://modrinth.com/mod/fabric-api) и видим название fabric-api. Вот именно его и нужно указать, как название, тогда всё  будет работать корректно.

**Использование программы:**\n
После запуска программы вас встречает консоль с тремя вариантами ответа:

1. *Автоустановщик модов* (Этот вариант установит все моды из settings.json в папку mods в той же директории, где находится и исполняемый файл, а если мода нет еще на эту версию, то запишет их в not_found_mods.json)
2. *Повторная проверка не загруженных модов* (Этот вариант установит все моды из not_found_mods.json. Если мод был найден, то программа автоматически его скачает и удалит из файла not_found_mods.json)
3. *Пересоздание файла not_found_mods.json* (Этот вариант просто пересоздает файл с не найденными модами, в некоторых случаях это полезно)
