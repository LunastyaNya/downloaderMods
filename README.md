# downloaderMods
Автозагрузчик модов для Minecraft.

### Использование
ЗАПУСКАТЬ main.py!!!! download.py НЕ ТРОГАТЬ!

После запуска кода у вас в папке с main файлом появится два файла:

- *settings.json*
- *not_found_mods.json*

В settings.json моды, которые
нужно будет установить, в not_found_mods.json будут записаны
моды, которые пока недоступны на новые версии.
